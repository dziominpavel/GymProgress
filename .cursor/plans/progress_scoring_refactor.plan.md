# Рефакторинг оценки прогресса по упражнению — план реализации

## Решения (зафиксировано)

- **Вариант E:** разная логика по целям (сила → E1RM, гипертрофия → объём, выносливость → объём/total reps).
- **Шкала:** 0–1000 баллов, где 1000 = 1.5× персональный макс (по истории **без** текущей сессии).
- **Сравнение:** текущая сессия vs **среднее за последние 3 сессии** (по метрике).
- **Прогресс в %:** `(метрика_сегодня − avg_последние_3) / avg_последние_3 × 100%` — по сырой метрике (объём или E1RM).
- **UI:** балл 0–1000 + статус (Лучше/Хуже) + % + краткая причина.

## Критичные правила

1. **Потолок:** theoretical_max всегда по истории **без** текущей сессии.
2. **Малая история:** при < 3 сессий — сравнение с 1–2; при 0 — «Первая тренировка».
3. **BW-упражнения:** effectiveLoad = bodyWeight + addedWeight; bodyWeight из настроек.

## Этапы реализации

1. **Метрики по целям** — объём (гипертрофия), E1RM (сила), объём/total reps (выносливость).
2. **Формула балла 0–1000** — score = (metric / (1.5 × max_metric_history)) × 1000, cap 1000.
3. **Сравнение** — avg(последние 3 метрики) + delta % + статус + причина.
4. **Рефакторинг WorkoutScoreCalculator** — заменить текущую логику.
