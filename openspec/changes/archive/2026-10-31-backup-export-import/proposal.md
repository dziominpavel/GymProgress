# Proposal

## Why

Auto Backup не гарантирует перенос данных между устройствами и не даёт пользователю понятной точки восстановления. После появления стабильных `clientId` и `exerciseId` появилась возможность сделать безопасный ручной экспорт/импорт: сохранить историю перед переустановкой, перенести её на новое устройство или выгрузить журнал для анализа.

## What Changes

- Добавить в настройки раздел «Резервное копирование»: экспорт JSON, импорт JSON и экспорт журнала в CSV.
- JSON-файл `schemaVersion: 1` содержит настройки, `trainerSettings`, упражнения (включая архивные) и записи журнала. Связь записи с упражнением — по `exerciseClientId`, без зависимости от локального `id`.
- Перед импортом показывать предпросмотр: сколько записей и упражнений в файле, сколько сейчас в приложении, сколько добавится/совпадёт/удалится.
- Реализовать две стратегии:
  - **«Объединить»** (по умолчанию) — ничего не удаляет, сопоставляет упражнения по `clientId` и `nameKey`, записи — по `clientId` и натуральному ключу; архивные упражнения и «сиротские» записи сохраняются.
  - **«Заменить всё»** — создаёт страховочный JSON-бэкап текущей БД в кэше, требует двойного подтверждения, затем в одной транзакции очищает данные и загружает файл.
- Настройки из файла применяются только при явно включённой галочке «Также применить настройки из файла»; по умолчанию остаются локальные.
- CSV-экспорт: UTF-8 с BOM, разделитель `;`, колонки «Дата;Упражнение;Мышечная группа;Вес;Повторы;Объём». Импорта CSV нет.
- Ошибки чтения/записи, повреждённый JSON, неподдерживаемая версия схемы и сбой транзакции показываются пользователю; база при ошибке остаётся нетронутой.
- Добавить общий страховочный бэкап для «Заменить всё» с возможностью поделиться файлом.

## Capabilities

### New Capabilities

- `data-backup`: ручной экспорт/импорт данных приложения в JSON, стратегии объединения и замены, предпросмотр, страховочный бэкап и экспорт журнала в CSV.

<!-- Нет: exercise-catalog и workout-logging уже описывают clientId/exerciseId; их требования не меняются. -->

## Impact

- **Новые файлы:** `data/backup/BackupSchemaV1.kt`, `data/backup/BackupRepository.kt`, `data/backup/ImportMerger.kt`, `data/backup/BackupCsv.kt`.
- **Данные:** `SettingsRepository` — снимок и применение всех настроек; `ExerciseDao`/`WorkoutDao` — `deleteAll` и пакетные вставки; `AppDatabase` — транзакции через существующий `withTransaction`.
- **ViewModel/UI:** `WorkoutViewModel` — экспорт, предпросмотр, импорт, CSV; `SettingsScreen` — новая секция и SAF-диалоги; `MainActivity` — проброс колбэков.
- **Сборка:** плагин `kotlinx.serialization` и зависимость `kotlinx-serialization-json`; `FileProvider` для страховочного бэкапа.
- **Тесты:** unit-тесты merge/CSV/валидации, androidTest для импорта в Room и отката транзакции.
- **Совместимость:** схема Room не меняется (версия 7); формат файла версионируется отдельно (`schemaVersion`).
